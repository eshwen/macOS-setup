Homebrew⚓︎

Homebrew is an excellent, open source package manager for macOS. It's full of useful GUI programs as well as command line utilities that can be easily installed.

It should keep them up to date without requiring conscious individual checks, and should install the right versions for my architecture (i.e., Intel x64 or Apple Silicon) and OS version.

Installation⚓︎

bootstrap.sh installs Homebrew and everything in the Brewfile. To install Homebrew by hand, follow the instructions at https://brew.sh/.(1) This should also install the Xcode Command Line Tools, which are useful for software development.(2)

  1. The installer prints the line to add Homebrew to your PATH. On Apple Silicon, it's eval "$(/opt/homebrew/bin/brew shellenv)" in ~/.zprofile.
  2. The manpage is at https://docs.brew.sh/Manpage, containing a bunch of useful commands like autoremove (to remove unused dependencies).

Packages⚓︎

Everything I install with Homebrew is in the Brewfile:

# CLI utilities
brew "emacs" # Not bundled with macOS since Catalina
brew "git", link: :overwrite # Newer than the version bundled with macOS
brew "gnupg" # For signing Git commits
brew "poetry" # For repos that still use Poetry
brew "pyenv" # For repos that still use pyenv
brew "tree"
brew "uv" # Default for Python installs, projects and environments
brew "wget"
brew "zsh" # Newer than the version bundled with macOS
brew "zsh-syntax-highlighting"
cask "antigravity-cli"

# GUI applications
cask "1password"
cask "adobe-creative-cloud" # Lightroom and other Adobe products
cask "android-file-transfer" # Copying files to Oculus Quest
cask "ankerwork" # Webcam configuration
cask "antigravity-ide"
cask "bibdesk", args: { appdir: "/Applications/TeX" } # Managing BibTeX references
cask "blackhole-64ch" # Capturing audio output alongside a screen recording
cask "chatgpt"
cask "discord"
cask "docker-desktop"
cask "filebot" # Batch renaming. If it won't open, run `xattr -dr com.apple.quarantine /Applications/FileBot.app`
cask "github"
cask "google-chrome"
cask "google-drive"
cask "google-gemini" # Desktop client for Gemini's chat interface
cask "handbrake-app"
cask "jetbrains-toolbox"
cask "logi-options+"
cask "mactex-no-gui" # TeX Live, without TeXShop, LaTeXiT, etc.
cask "mimestream" # Gmail client. Requires a subscription
cask "mkvtoolnix-app" # Adding/removing audio and subtitle tracks in MKV files
cask "obsidian"
cask "plex"
cask "quicklook-video" # Thumbnails for MKV and other video formats
cask "raindropio"
cask "runescape"
cask "sidequest" # Sideloading content onto Oculus Quest
cask "steam"
cask "surfshark"
cask "tailscale-app" # Remote access to other devices, e.g., a NAS
cask "tex-live-utility", args: { appdir: "/Applications/TeX" } # Updating TeX Live packages
cask "the-unarchiver" # More versatile than the built-in archive utility
cask "thebrowsercompany-dia"
cask "todoist-app"
cask "vivid-app" # Higher display brightness. Requires a licence
cask "vlc"
cask "warp" # A nicer, modern terminal with agentic capabilities and settings sync
cask "whatsapp"

Install or update them all with

brew bundle install --file ~/GitHub/macOS-setup/Brewfile

To add a package, add it to the Brewfile rather than running brew install, so it's installed on every Mac. brew bundle cleanup --file ~/GitHub/macOS-setup/Brewfile lists anything installed that isn't in the Brewfile (add --force to uninstall them).

brew lines install formulae (command line tools), and cask lines install GUI applications into the Applications folder. Some programs come as both, e.g., handbrake is the command line version and handbrake-app is the GUI.

For any issues with opening these programs, see https://support.apple.com/en-gb/guide/mac-help/mh40616/mac.

Updating⚓︎

Upgrade Homebrew packages with

brew upgrade
brew upgrade --cask

Casks with auto-update utilities (like a lot of GUI applications) won't be updated when the above commands are run; the built-in updaters will maintain them in those cases. To force them to update with Homebrew, run

brew upgrade --greedy

Viewing⚓︎

Check everything that's installed with

brew list

Check only top-level formulae with

brew leaves

Add the -r option for formulae that were explicitly installed, or -p for formulae installed as a dependency of a cask.

Check which formulae and casks are using a specific dependency with

brew uses --installed --recursive <dependency>

Cleanup and uninstalling⚓︎

Homebrew should run a cleanup of caches and old files every so often. For manual scrubbing, run

brew cleanup -s --prune all

Uninstall a formula/cask with

brew uninstall <formula/cask>

Add the --zap option to remove all associated files.

Uninstall unused dependencies of formulae/casks with

brew autoremove
